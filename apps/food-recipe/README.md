# 🍳 FoodRecipe Pro — Culinary Explorer & Checklist (`@portfolio/food-recipe`)

Explorador gastronómico y gestor de recetas con arquitectura **Feature-Sliced Design (FSD)** integrado en `/projects/food-recipe/`. Construido con **React 18**, **React Router v6**, **Context API** y **Tailwind CSS**.

## ✨ Características Clave
- **Buscador Culinario**: Consulta de recetas internacionales con carga diferida por rutas (`React.lazy`).
- **Checklist Interactiva de Ingredientes**: Seguimiento paso a paso de ingredientes y tiempos de cocción.
- **Gestión de Favoritos**: Persistencia local de recetas favoritas sincronizada mediante Context API.

## 🚀 Desarrollo
```bash
pnpm --filter @portfolio/food-recipe dev
pnpm --filter @portfolio/food-recipe build
```
